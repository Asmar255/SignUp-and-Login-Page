# 📱 SignUp & Login Mobile App

A responsive, cross-platform authentication UI built with **React Native**, **Expo Router**, and **TypeScript**. This project showcases clean UI design, custom input state management, form validation, and seamless screen navigation.

## ✨ Features

* **User Authentication & Validation:** Input validation for email and password fields, complete with mock login verification and native error alerts.
* **Custom Password Toggle:** Integrated `eye` / `eye-off` visibility toggle placed directly inside the password input border.
* **Expo Router Navigation:** Declarative file-based routing managing transitions between `/Login` and `/SignUp`.
* **Keyboard & View Handling:** Optimized mobile layout preventing software keyboard overlap using screen context wrappers.
* **Social Auth UI:** Styled touchable elements for Google and Apple single sign-on options.

## 🚀 Getting Started

### Prerequisites

Ensure you have Node.js installed on your machine along with the [Expo Go](https://expo.dev/go) app on your mobile device (or an Android/iOS emulator configured).

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/Asmar255/SignUp-and-Login-Page.git](https://github.com/Asmar255/SignUp-and-Login-Page.git)
   cd login-signup-project

```

2. Install dependencies:
Bash

```
npm install

```

3. Start the development server:
Bash

```
npx expo start

```

4. Launch the application:
   * Scan the QR code in your terminal using Expo Go (Android) or the native Camera app (iOS).
   * Press `a` in the terminal to launch on an active Android Emulator.
